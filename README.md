# Юнайтед Благоевград — лесен сайт за GitHub Pages

Тази папка съдържа напълно готов статичен сайт. Няма инсталации, акаунти, база данни или сложен код.

## Как да го отвориш на компютъра

Отвори файла `index.html` с двоен клик. Сайтът ще се зареди в браузъра.

## Как да променяш сайта

- Текстовете са във файла `index.html`. Отвори го с Notepad или друг текстов редактор.
- Цветовете са в началото на файла `style.css`.
- Снимките са в папката `images`.
- Ако искаш да смениш снимка, сложи новата в `images` със същото име: `team1.jpg`, `team2.jpg` или `logo.jpg`.
- В `index.html` има коментари, които показват къде се променят основните текстове.

## Как да го качиш в GitHub Pages

1. Влез в GitHub и създай ново публично хранилище.
2. Натисни **Add file → Upload files**.
3. Качи съдържанието на тази папка: `index.html`, `style.css`, `README.md` и папката `images`.
4. Отвори **Settings → Pages**.
5. На **Source** избери **Deploy from a branch**.
6. Избери клона **main**, папка **/(root)** и натисни **Save**.
7. След кратко изчакване GitHub ще покаже адреса на сайта.

Важно: файлът трябва да остане с име `index.html`, защото GitHub Pages го използва като начална страница.
