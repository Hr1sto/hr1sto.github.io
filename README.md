# United Blagoevgrad — сайт за GitHub Pages

Статичен сайт с HTML, CSS и малко JavaScript. Няма инсталация, build стъпка или външни зависимости.

## Страници

- `index.html` — начало
- `about.html` — клуб
- `team.html` — отбор
- `matches.html` — мачове
- `news.html` — новини
- `gallery.html` — галерия
- `contact.html` — контакти

Всички страници са директно в основната папка. За преглед без сървър отворете `index.html` с двоен клик.

## Основни файлове

- `style.css` — общ дизайн за всички страници
- `script.js` — mobile меню и lightbox в галерията
- `images/` — логото, снимките на отбора и снимката на треньора

## Лесно редактиране

В HTML файловете има коментари за:

- следващ мач и последен резултат;
- новини;
- футболисти;
- история на клуба;
- контакти.

## GitHub Pages

Качете цялото съдържание на тази папка в хранилището `hr1sto.github.io`. В **Settings → Pages** задайте **Deploy from a branch**, клон **main**, папка **/(root)**.

Всички вътрешни връзки и файлове използват относителни пътища и работят директно през GitHub Pages.
